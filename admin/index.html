Roy's Admin Panel

To add or edit books and events, open the entries file on GitHub, make your changes, and save. It’s just like editing a document!

Edit entries.json on GitHub Upload book covers / icons

How to add an entry

  1. Click the button above to open the editor
  2. Add a new entry inside the "entries": [...] list, for example:
    { "type": "book", "date": "2026-07-24",
      "title": "My New Book",
      "coverImage": "", "details": "..." }
  3. Scroll down and click "Commit changes"
  4. The site updates automatically in about a minute!

Only GitHub collaborators on this repo can save changes.
